## HideSelf Adaptation

- Синхронизировано с upstream тегом `v1.11.4`.
- Формат релиза HideSelf runtime не меняется: публикуется managed Windows binary `hideself-tgws_windows.exe`.
- При merge-конфликте для fork-owned файлов сохраняется версия HideSelf (`.github/workflows/build.yml`, `docs/README.md`).
- Сборка `hs.34`: Cloudflare-прокси и свой Worker сами переходят на соединение без TLS, если по TLS ответа нет. Раньше для этого нужно было включить «без TLS» и перезапустить модуль; теперь мост пробует `ws://` рядом с `wss://` через 2,5 с тишины и запоминает, что сработало. Флаг `--no-secure` по-прежнему оставляет только соединение без TLS.
- Там же: соединение, на котором запросы Telegram остаются без ответа 6 секунд, мост закрывает сам. Telegram ждал такое соединение 15–16 секунд и только потом открывал новое, которое отвечало сразу, — отсюда «не подключается, потом подключился». Порог задаётся `--stall-timeout`, 0 выключает.
- Там же: когда все домены Cloudflare-прокси на выдержке после сбоев, мост не отказывает Telegram сразу, а раз в 5 секунд пробует те, что провинились меньше всех.
